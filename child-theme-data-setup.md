# Alur Isi Data Child Theme Tour1

## Customize

1. Isi **Customize Velocity Theme**:

   1. **Site Identity**: logo, site title, tagline, site icon.
   2. **Kontak Header**: no telepon, no whatsapp, dan email.

      * Apabila tidak ada data dari client, ambil dari form isian website.
   3. **Halaman Depan - Banner**: gambar besar, gambar kecil 1, gambar kecil 2, judul, keterangan, teks tombol, link tujuan.
   4. **Halaman Depan - Keunggulan**: judul keunggulan, daftar keunggulan: icon-nama-deskripsi.
   5. **Halaman Depan - Galeri**: judul, galeri foto: gambar galeri.
2. **Site Identity**: logo, site title, tagline, site icon.
3. **Theme Color**: sesuaikan dengan warna logo

## Widgets

* Pada **Main Sidebar**: widgets search dengan title "Pencarian", widgets text dengan title "Paket Wisata" dan content kategori paket, dan widgets calendar.
* Pada **Footer 1**: widgets text dengan title dan content Kontak Kami.
* Pada **Footer 2**: widgets recent posts.
* Pada **Footer 3**: widgets text: title "statistik pengunjung" dan content statistik \[velocity-statistics].

## Gallery

* Aktifkan fitur **Gallery Post Type** di Velocity Addon.
* Gunakan shortcode **VD Gallery** untuk tampilan halaman gallery.

## Logo Header

* Apabila warna logo tidak kontras dengan background belakangnya, berikan **background putih**.

## Halaman Home

* Set halaman **Home** mengambil template **"Home Template"**.

## Paket Tour

* Isikan data **Paket Tour** dengan data dari client.
Jika klien tidak mengirim data, bisa di isi contoh sesuai materi.
*Apabila belum ada CPT **Paket Tour**, install plugin <b>Velocity Tour \& Travel</b>*
